# F1 Lap Analysis

F1のレース・予選・スプリントにおけるドライバーのパフォーマンスをインタラクティブに可視化するWebアプリケーション。

## 機能

- **セッション選択** — 2018〜2025年のグランプリ、セッションタイプ（Race / Qualifying / Sprint）を選択可能
- **ラップタイム比較** — 最大5名のドライバーのラップタイム推移をタイヤコンパウンド別に表示。ピットストップのタイミングも自動検出
- **テレメトリー比較** — 任意のラップのスピード・スロットル・ブレーキデータをドライバー間で比較
- **トラックマップ** — スピードをヒートマップで重ねたサーキット上の走行ライン表示
- **ラップデータ閲覧** — ラップタイム・タイヤ種別・スティント情報の一覧表示

## 使用技術

| カテゴリ | ライブラリ |
|----------|-----------|
| フレームワーク | Streamlit |
| F1データ取得 | FastF1 |
| データ処理 | Pandas |
| グラフ描画 | Plotly |
| 実行環境 | Docker |

## セットアップ

### 前提条件

- Docker / Docker Compose がインストールされていること

### 手順

```bash
# 1. リポジトリのクローン
git clone https://github.com/Non-penguin/f1-analysis-app
cd f1-analysis-app

# 2. ビルド & 起動
docker compose up

# バックグラウンドで起動する場合
docker compose up -d
```

> 権限エラーが出る場合は `sudo docker compose up` で実行してください。

### アクセス

```
http://localhost:8501
```

## キャッシュについて

FastF1 が取得したデータは `./ff1_cache` ディレクトリに保存されます。
Docker ボリュームとしてマウントされているため、コンテナを再起動してもキャッシュは保持されます。
